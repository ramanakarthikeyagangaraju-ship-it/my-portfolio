# Personal Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Features
- About, education, skills, projects, and contact sections
- Responsive layout for desktop and mobile
- Interactive navigation and UI elements

## Run locally
Open `index.html` in your browser.

## Deploy with GitHub Pages
1. Open the repository Settings.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. Your site will be published at `https://ramanakarthikeyagangaraju-ship-it.github.io/my-portfolio/`.

## Customize
Update the content in `index.html`, styling in `styles.css`, and interactions in `script.js`.
